# Examples
- `llms.txt.example` — the llms.txt template, completely filled in for a
  fictional publication, so you can see the intended shape line by line.
- `spec-add-blog-article/` — a complete mini spec package (spec/plan/tasks)
  for the most common job there is: adding one blog article the governed
  way, gate included.
Both examples are fictional and safe to copy as starting points.
